# SP2 Build Assistant 0.5.0

[English](../Release-0.5.0.md) · 简体中文

0.5.0 新增精确装配和局部精修能力。已安装较早版本时，退出游戏后按 [安装与升级](Installation.md) 同步更新 DLL 和 CLI。

- 查询零件当前有效值、默认值、资源选项和可写条件，并编辑受支持的窗体、文字、贴花、材质和机构参数。
- 按显式坐标系和枢轴移动刚性部件组，或按挂点对齐。连接命令负责建立拓扑，需要对齐时另外执行定位。
- 从设计器实际网格测量间隙、截线和采样接缝误差，通过固定相机复拍和状态差异检查修改。
- 批量提交连续编辑，并用当前会话的检查点恢复。设计器导航可通过原生接口进入场景、加载和选中目标。

代表性精修、截图和恢复场景已验证。部分原生属性的可用性取决于零件类型和资源。三心和网格测量用于设计检查，飞行表现及完整机构轨迹需另行测试。
