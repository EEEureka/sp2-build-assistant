# SP2 Build Assistant 0.5.0

English · [简体中文](zh-CN/Release-0.5.0.md)

Version 0.5.0 adds precision assembly and local refinement. To upgrade, close the game and install the DLL and CLI together. [Installation and updates](Installation.md)

- Discover effective part values, defaults, resources and write conditions. Edit supported windows, text, decals, materials and mechanisms.
- Position rigid groups using explicit coordinate frames and pivots. Align attachment points and connect the parts as separate steps.
- Measure clearances, cross-sections and sampled seam errors from native meshes. Compare matching native views and craft-state differences.
- Apply edits in batches and recover from checkpoints in the current designer session. Native designer navigation can load a saved craft and select target parts.

Representative refinement, capture and recovery scenarios were validated. Supported properties depend on the native part type and available resources. Use the designer measurements to review the layout and test flight behavior and full mechanism motion separately.
