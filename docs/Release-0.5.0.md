# 0.5.0 版本说明

状态：2026-10-05，正式版本已部署并完成加载核对及必需回归。250轮长期验收和局部精修代表场景通过；能力边界、内存曲线限制及安装身份见[最终验收报告](Verification-0.5.0.md)。调用见[中文局部精修指南](Precision-Workflow.md)。

本版围绕“选定一小组部件，查有效参数，精确修改，看固定视图，量误差，不满意就恢复”的工作方式展开。它支持精细建造所需的局部操作；从照片自动恢复尺寸、完整Animator编辑和连续机构碰撞检测仍不在本版范围内。

## 能力变化

| 场景 | 工具入口 | 解决的问题 |
| --- | --- | --- |
| 查找原生参数、有效值与条件 | `properties describe/get`、`resources list` | 区分XML省略、有效默认、只读、条件可写和未支持；模板查询包含当前飞机没有使用的零件 |
| 窗体、文字/贴花、罩与机构属性 | `properties.set` | 提供具名字段、单位、原生资源选项、边界校验及回调刷新；双铰轴Pose、切割目标、起落架挂载条件分别解释 |
| 局部涂装 | `appearance get`、`appearance.set` | 区分克隆材质后只改目标槽与显式共享修改；支持当前飞机的纹理、颜色、表面和昼夜发光参数 |
| 装配精修 | `groups resolve`、`transform.apply/align`、`decal.pose.get/set` | 显式坐标系与枢轴，保持组内刚性关系，识别原生随动和镜像作用域；普通连接仍不强制吸附 |
| 测量误差 | `geometry measure/section/seam/symmetry` | 从真实网格给见证点、截线、已采样接缝误差和完整性；区分渲染网格与碰撞体 |
| 连续微调 | `designer capture`、`craft diff`、检查点/回滚 | 固定取景复拍、相机恢复诊断、完整状态差异和安全恢复；原生图用于材质/透明/文字，分析图用于部件及空间关系 |
| 后台操作设计器 | `designer crafts/control` | 经原生API加载、进入、选择、返回菜单和退出，不模拟桌面键鼠；仍只编辑已在设计器加载的飞机 |
| 连续纯数据编辑 | `batch apply` | 保留操作顺序，合并可安全连续处理的段；回传重建次数、耗时、有效变化与完整验证 |

## 已取得的主要证据

- 94个必需通用属性适配字段均有代表场景的正向原生参考与负向测试。基础矩阵206项，非法输入矩阵471项；复杂矩阵原始失败分类保留，后续29项复验通过。17种起落架样式的27项检查通过，包括动画数据保留和样式变化后继续编辑。逐字段索引见[适配字段证据](../knowledge/native-adapter-evidence.json)。
- 夜间/白天材质shader分支已执行并查看原生图；实际窗口切割、鼠标拾取、镜像、复杂连接及机构离散端点的历史实机证据继续保留。
- E1机头玻璃、E2挂架/吊舱/贴花、E3腿轮/舱门/活塞均完成三个固定起点各两轮局部精修。它们是可核算目标上的开发者自验，不是外部Agent盲测，也不等于整架C17外观得到用户认可。
- 原始0.4.11和新版各30个同条件样本：874件飞机、同组8件raw属性编辑，完整状态均正确。中位数11.971秒→3.874秒，降低67.64%；新版每批重建1次，p95为4.452秒。原生重载准备不计入编辑耗时，全部样本保留。报告见 `tests/artifacts/precision-0.5.0/relative-performance-native-reset.json`。
- 无钩子编译隔离、74项Python及C#核心测试通过；skill结构与13个本地链接通过。四批1415、1582、406、109个真实CLI信封schema校验零错误。正式无钩子DLL的3+9+16+18项功能回归、14组网格/55项表达式对照通过；长测1283份及最终回归217份实际返回schema零错误。

## 调用约定与边界

统一使用全局 `sp2build`。先运行 `sp2build version --json`、`sp2build designer status --json`，再查询具体命令的 `commands schema`；安装新版CLI不等于已加载新版DLL。DLL更新仍需退出再启动游戏。

写入使用当前session、revision及唯一requestId。部件ID可能复用，重载会使检查点与旧引用失效。导航的载入、返回菜单、退出需要明确的discardCurrent守卫；保存操作仍遵循游戏自身流程。启动尚未运行的进程需要本地启动器，游戏内插件无法在没有游戏进程时自行运行。

`properties.set`索引中的94是适配字段数量，不是全部4529个类型/字段对的认证数量。未测原生类型/动态组合不自动继承通过状态。查询live条件与资源后再构造补丁；更换起落架样式后重新读取可用挂点相关字段。

原生截图需由Agent实际打开。多视图轮廓只能证明所查看视角，采样接缝不能给连续曲面的严格最大误差，离散收放端点不能证明完整轨迹无碰撞。三心查询仍是设计器布局辅助，不独立证明静稳定性或可飞行性。

完整操作步骤见[CLI手册](CLI-Usage.md)及skill中的[精细建造方法](../skills/sp2-build-assistant/references/precision-building.md)、[原生导航](../skills/sp2-build-assistant/references/designer-navigation.md)。
