# S02 反馈修订：CLI / skill 0.4.3，DLL 0.4.0

日期：2026-10-02。本轮仅修 CLI 参数诊断，游戏 DLL 未变，不需要重启。

FB-026 的诊断问题成立：不存在的 `craft centers --include-disconnected` 裸写时，旧解析器先报“requires a value”，补值后才报 Unknown option。0.4.3 先根据完整命令判断缺值参数是否合法，未知参数两种写法均明确拒绝；合法的 `--id` / `--baseline` / `--output` 等仍报缺值，`--images` 开关仍可裸写。普通命令的输入校验移到实例发现前，错误参数无需运行游戏也可诊断。新增回归检查及既有 Python 检查共 49 项通过。

“存在一个未文档化的 include-disconnected 开关”不成立：该命令从未在 schema/help 声明此参数；全局帮助里的 `connections.disconnect` 是另一个命令。三心沿用原生连接到主控制器的范围，本轮没有增加任意范围重新计算的能力。

S02 同时纠正了验收报告的推断：当前为单侧翼，约 7.07 m 整机 X 范围；12.83 m 是镜像后的预计双侧翼展。平移后射线 Z 坐标符号写反造成了 0.3 m 采样位置变化，不能归因于碰撞网格重生成。四站位的线性分段梯形面积约 12.895 m²，仅作为量级检查；原生投影权重 12.83059 的差异不能无证据归因于端帽。报告与台账应保留更正依据。
